# Atajos de teclado

| Dónde | Tecla | Acción |
|---|---|---|
| Global | Ctrl+F | Ir al cuadro de búsqueda |
| Global | Ctrl+Mayús+I | Importar carpeta o unidad |
| Cuadrícula | Flechas / Tab | Moverse entre elementos |
| Cuadrícula | Ctrl+clic, Mayús+clic, Ctrl+A | Selección múltiple / rango / todo |
| Cuadrícula | Intro o doble clic | Abrir en el visor |
| Cuadrícula | Supr | Mover a Eliminados recientemente (en Eliminados recientemente: eliminar definitivamente, con confirmación) |
| Cuadrícula | Esc | Quitar la selección |
| Cuadrícula | Clic derecho | Menú contextual (favorito, álbum, palabras clave, exportar, ocultar, eliminar) |
| Visor | ← / → | Anterior / siguiente |
| Visor | F | Pantalla completa |
| Visor | Esc | Salir de pantalla completa / volver |
| Visor | I | Panel de información |
| Visor | E | Editar |
| Visor | R | Girar la vista (no modifica el archivo) |
| Visor | M | Comparar con el original (si está editada) |
| Visor | . | Favorito |
| Visor | Supr | Mover a Eliminados recientemente |
| Visor | Doble clic / rueda + Ctrl / pellizco | Zoom |
| Editor | Ctrl+Z / Ctrl+Y | Deshacer / rehacer |
| Editor | Ctrl+S | Guardar (Listo) |
